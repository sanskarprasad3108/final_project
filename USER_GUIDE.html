1. Docker Setup & Installation

Prerequisites

Before running the application, ensure you have Docker installed on your system.

Step 1: Install Docker Desktop

  1. Visit: https://www.docker.com/products/docker-desktop/
  2. Download Docker Desktop for your operating system (Windows/Mac/Linux)
  3. Run the installer and follow the setup wizard
  4. Restart your computer after installation
  5. Launch Docker Desktop and wait for it to start (whale icon in system tray)
✅ Verify Docker Installation:
docker --version

You should see: Docker version 24.x.x or higher

2. Running the Application

Method 1: Pull from Docker Hub (Recommended)

The easiest way to run the application - no source code needed!

1 Pull the Docker Image

docker pull sanskar3108/dump-truck-anomaly-detector:latest

2 Run the Container

docker run -d -p 5000:5000 --name dump-truck-app sanskar3108/dump-truck-anomaly-detector:latest

3 Open in Browser

http://localhost:5000
🎉 That's it! The application is now running. Open your browser and navigate to http://localhost:5000

Method 2: Build from Source Code

If you have the source code files:

1 Navigate to Project Folder

cd path/to/project/folder

2 Build and Run with Docker Compose

docker compose up --build

Useful Docker Commands

Command Description
docker ps List running containers
docker stop dump-truck-app Stop the container
docker start dump-truck-app Start the container again
docker logs dump-truck-app View container logs
docker rm dump-truck-app Remove the container

4. Simulation Controls

Control Buttons

Button Action Description
📊 Simulate Normal Click to Start/Stop Starts real-time sensor data simulation with normal operating values
🔥 INJECT FAILURE 🔥 Click to Toggle Injects anomalies into randomly selected components based on failure probability weights
▶ Start Stream Click to Start Begin continuous data streaming
⏹ Stop Click to Stop Pause the simulation

Status Indicators

  • ● Green Dot - Inject Failure: OFF (System running normally)
  • ● Red Blinking Dot - Inject Failure: ON (Anomalies being injected)
⚠️ Note: When "Inject Failure" is active, the system randomly selects components to fail based on the probability weights. Multiple components can fail simultaneously.

7. Explainable AI (XAI) Features

When an anomaly is detected in any component, the XAI system provides human-readable explanations of why the anomaly was flagged.

XAI Explanation Panel

Appears automatically in component interfaces when anomaly is detected.

Feature Contribution Bars

Visual bar chart showing which sensors contributed most to the anomaly detection:

  • Bars are sorted by contribution percentage (highest first)
  • Color intensity indicates severity of deviation
  • Each bar shows the feature name and percentage contribution

Natural Language Explanation

Human-readable text explaining the anomaly. Example:

"Engine anomaly detected primarily due to critically elevated engine temperature, contributing 65% of the total deviation. This indicates overheating condition. Elevated oil pressure (25%) further indicates lubrication system stress."

How XAI Works

  1. Reconstruction Error - The autoencoder model computes reconstruction error for each sensor
  2. Feature Attribution - Per-feature errors are calculated and normalized to percentages
  3. Severity Assessment - Contribution levels are mapped to severity adjectives (critically, significantly, notably, moderately, slightly)
  4. Cause Mapping - High-contributing features are mapped to domain-specific cause descriptions
  5. Text Generation - Natural language explanation is generated from the analysis

9. Quick Start Tutorial

Step-by-Step Walkthrough

1 Start Normal Simulation

  1. Click the 📊 Simulate Normal button
  2. Watch sensor values stream in real-time
  3. All indicators should be green
  4. Observe the truck diagram - all components have green glow

2 Inject a Failure

  1. Click the 🔥 INJECT FAILURE 🔥 button
  2. Watch the system randomly select components to fail
  3. Observe the changes:
    • Status changes to "ANOMALY DETECTED"
    • Truck diagram shows smoke from failing components
    • Sensor cards turn red for anomalous readings
    • 3D plot shows a red point
    • History table logs the anomaly

3 Investigate the Anomaly

  1. Click on the failing component icon (e.g., 🔧 ENGINE)
  2. View the XAI Explanation Panel:
    • See which sensor caused the anomaly
    • Read the natural language explanation
    • Understand the severity and recommended actions
  3. Click ← Back to Dashboard to return

4 Use the Chatbot

  1. Click the 🤖 robot icon (bottom-right)
  2. Ask: "What is the current system status?"
  3. Or describe an issue: "Engine is overheating"
  4. Get detailed causes, fixes, and prevention tips

5 Stop Injection

  1. Click 🔥 INJECT FAILURE 🔥 again to turn it off
  2. System returns to normal operation
  3. All indicators return to green

6 Export History

  1. Scroll to the Past Anomaly History panel
  2. Click 📥 Export to download CSV file
  3. Use for further analysis or reporting

10. Troubleshooting

Common Issues & Solutions

Issue Solution
Port 5000 already in use Use a different port: docker run -p 8080:5000 ...
Then access via http://localhost:8080
Docker not running Start Docker Desktop application and wait for it to initialize
Permission denied Run terminal as Administrator (Windows) or use sudo (Linux/Mac)
Container exits immediately Check logs: docker logs dump-truck-app
Page not loading Verify container is running: docker ps
Check if port mapping is correct
Charts not updating Click "Start Stream" button or refresh the page
Chatbot not responding Check browser console for errors (F12), refresh page
